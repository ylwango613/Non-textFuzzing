# vuln_002 – AP4_EsDescriptor SubStream Integer Underflow

## Vulnerability Summary

| Field | Value |
|---|---|
| **CWE** | CWE-191 – Integer Underflow (Wrap-Around) |
| **Binary** | `mp42aac` (Bento4) |
| **Function** | `AP4_EsDescriptor::AP4_EsDescriptor(AP4_ByteStream&, AP4_Size header_size, AP4_Size payload_size)` |
| **Source file** | `Source/C++/Core/Ap4EsDescriptor.cpp` |

## Root Cause

The constructor checks `AP4_ES_DESCRIPTOR_FLAG_URL` **twice** when it should check
`AP4_ES_DESCRIPTOR_FLAG_OCR_STREAM` for the second check (reading `m_OcrEsId`):

```cpp
// First check – correct
if (m_Flags & AP4_ES_DESCRIPTOR_FLAG_URL) {
    unsigned char url_length;
    stream.ReadUI08(url_length);
    ...
}
// Second check – BUG: should be AP4_ES_DESCRIPTOR_FLAG_OCR_STREAM
if (m_Flags & AP4_ES_DESCRIPTOR_FLAG_URL) {   // <-- wrong flag
    stream.ReadUI16(m_OcrEsId);               // reads 2 extra bytes
}
```

Flag values (stored in `m_Flags = (bits>>5) & 7`):

| Constant | Value | Byte value when only that bit set |
|---|---|---|
| `AP4_ES_DESCRIPTOR_FLAG_STREAM_DEPENDENCY` | 1 | 0x20 |
| `AP4_ES_DESCRIPTOR_FLAG_URL` | 2 | 0x40 |
| `AP4_ES_DESCRIPTOR_FLAG_OCR_STREAM` | 4 | 0x80 |

## Trigger Condition

Craft an `ES_Descriptor` (tag `0x03`) with:

| Field | Value | Bytes consumed |
|---|---|---|
| `payload_size` (declared in header) | 5 | — |
| `es_id` | 0x0001 | 2 |
| flags byte | 0x40 → `m_Flags = 2` (URL) | 1 |
| `url_length` | 0x00 | 1 |
| `url_string` | "" (0 bytes) | 0 |
| `OcrEsId` (read due to bug, URL flag set) | from stream | 2 |
| **Total consumed** | | **6** |

Underflow: `payload_size(5) − AP4_Size(offset − start)(6) → 0xFFFFFFFF ≈ 4 GB`

The resulting `AP4_SubStream` of ≈ 4 GB is handed to
`AP4_DescriptorFactory::CreateDescriptorFromStream`, which then attempts to read
descriptors from far beyond the actual file data.

## Trigger Path

```
mp42aac::main()
  → AP4_File(stream)
    → AP4_AtomFactory::CreateAtomFromStream()   [moov/trak/mdia/minf/stbl/stsd/mp4a]
      → AP4_EsdsAtom::Create()
        → AP4_DescriptorFactory::CreateDescriptorFromStream()
          → AP4_EsDescriptor(stream, header_size=2, payload_size=5)
            → payload_size − consumed(6) → underflow → ~4 GB SubStream
              → AP4_DescriptorFactory::CreateDescriptorFromStream(*substream)
                → OOB read
```
