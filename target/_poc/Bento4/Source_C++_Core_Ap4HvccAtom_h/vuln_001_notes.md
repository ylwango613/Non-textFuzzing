# VULN 001 – Off-by-One Heap OOB Read in AP4_HvccAtom Payload Parser

## Summary

**File**: `Bento4/Source/C++/Core/Ap4HvccAtom.cpp`  
**Line**: 282  
**CWE**: CWE-125 (Out-of-bounds Read)  
**Severity**: Medium (information disclosure / potential crash)

---

## Root Cause

`AP4_HvccAtom::Create()` (line 82-91) computes `payload_size = size - 8` and allocates
exactly that many bytes before calling the private constructor.

The private constructor `AP4_HvccAtom(AP4_UI32 size, const AP4_UI08* payload)` (line 248):

```cpp
unsigned int payload_size = size - AP4_ATOM_HEADER_SIZE;  // = size - 8

if (payload_size < 22) return;   // guard: ONLY returns when payload_size < 22
                                  // when payload_size == 22, condition is FALSE
// ... reads payload[0] through payload[21] (all in-bounds for a 22-byte buffer)

AP4_UI08 num_seq = payload[22];  // LINE 282: OOB read — buffer is only 22 bytes!
```

The off-by-one: the guard condition uses strict `<` instead of `<=`, so when
`payload_size` is exactly 22, parsing continues and accesses the 23rd byte
(index 22) which is one past the end of the heap allocation.

---

## Trigger Condition

Craft an hvcC box with `size = 30`:
- `payload_size = 30 - 8 = 22`
- Guard `22 < 22` is **false** → falls through
- `payload[22]` is read one byte past the 22-byte heap allocation

The hvcC box must be embedded inside a valid MP4 container so that Bento4's
atom factory parses down to it:

```
ftyp
moov
  mvhd
  trak
    tkhd
    mdia
      mdhd
      hdlr  (handler_type = 'vide')
      minf
        vmhd
        dinf
          dref
        stbl
          stsd
            hvc1  (VisualSampleEntry)
              hvcC  ← size=30, payload=22 bytes  (TRIGGER)
          stts / stsc / stsz / stco  (empty)
```

## Fix

Change the guard from strict less-than to less-than-or-equal:

```cpp
// Before (vulnerable):
if (payload_size < 22) return;

// After (fixed):
if (payload_size <= 22) return;
// Or equivalently:
if (payload_size < 23) return;
```

This ensures that when the payload is exactly 22 bytes (the minimum needed for
bytes 0-21), the constructor returns before attempting to read `payload[22]`.
