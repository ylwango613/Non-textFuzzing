# VULN-001: Heap OOB Read in AP4_BitReader::ReadCache() via Crafted dac4 Box

## Summary

A heap out-of-bounds read occurs in `AP4_BitReader::ReadCache()` when parsing
an AC4 DSI v1 box (`dac4`) whose payload is exactly 11 bytes and whose
`n_presentations` field is greater than zero.

## Affected Binary

`mp42aac` (Bento4)

## Vulnerable Code Locations

| File | Function | Line |
|------|----------|------|
| `Source/C++/Core/Ap4Utils.cpp` | `AP4_BitReader::ReadCache()` | ~430 |
| `Source/C++/Core/Ap4Dac4Atom.cpp` | `AP4_Dac4Atom::AP4_Dac4Atom()` | ~117 |

## Root Cause

`AP4_BitReader::ReadCache()` reads four bytes at `m_Buffer.GetData() + m_Position`
without any bounds check:

```cpp
AP4_BitReader::BitsWord
AP4_BitReader::ReadCache() const
{
    const AP4_UI08* out_ptr = m_Buffer.GetData()+m_Position;
    return (((AP4_BitReader::BitsWord) out_ptr[0]) << 24) |
           (((AP4_BitReader::BitsWord) out_ptr[1]) << 16) |
           (((AP4_BitReader::BitsWord) out_ptr[2]) <<  8) |
           (((AP4_BitReader::BitsWord) out_ptr[3])      );
}
```

The `AP4_BitReader` constructor pads the input buffer to the next multiple of
four bytes (AP4_WORD_BYTES = 4).  For an 11-byte payload the internal buffer
is 12 bytes (indices 0–11).

When parsing an `ac4_dsi_v1` block with `bitstream_version ≤ 1`:

| Call | Bits consumed | Running total |
|------|---------------|---------------|
| ReadBits(3) – ac4_dsi_version | 3 | 3 |
| ReadBits(7) – bitstream_version | 7 | 10 |
| ReadBits(1) – fs_index | 1 | 11 |
| ReadBits(4) – frame_rate_index | 4 | 15 |
| ReadBits(9) – n_presentations | 9 | 24 |
| *(UUID block skipped, bsv ≤ 1)* | | |
| ReadBits(2) – bit_rate_mode | 2 | 26 |
| ReadBits(32) – bit_rate | 32 | 58 |
| ReadBits(32) – bit_rate_precision | 32 | 90 |
| *Byte-align: SkipBits(6) (90 % 8 = 2)* | 6 | 96 |

After the byte-align step: `m_Position = 12`, `m_BitsCached = 0`.

The presentation loop then calls `ReadBits(8)` for `presentation_version`
(line 117 of `Ap4Dac4Atom.cpp`).  Because `m_BitsCached == 0`, this
immediately calls `ReadCache()` at `m_Position = 12`, reading four bytes
beginning at index 12 – one byte past the end of the 12-byte heap buffer.

## Trigger Conditions

1. The `dac4` box payload is exactly **11 bytes** (the minimum that passes
   the `if (payload_size < 11) return;` guard).
2. `ac4_dsi_version == 1` (bits 0–2 = `001`).
3. `bitstream_version ≤ 1` (bits 3–9 ≤ 1) so the UUID block is skipped.
4. `n_presentations ≥ 1` (bits 15–23 > 0) so the presentation loop is entered.
