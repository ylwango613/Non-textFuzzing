# VULN 001 – Integer Underflow in AP4_DecoderConfigDescriptor (Bento4)

## Status: VERIFIED_CRASH

UBSAN reports two null-pointer violations when running `mp42aac` against `vuln_001.mp4`.

## Vulnerability Summary

**File**: `Bento4/Source/C++/Core/Ap4DecoderConfigDescriptor.cpp`, line 92
**Type**: Integer underflow (unsigned wrap-around) → OOB read → null-pointer dereference

### Vulnerable Code

```cpp
AP4_SubStream* substream = new AP4_SubStream(stream, start+13, payload_size-13);
```

`payload_size` is `AP4_UI32` (unsigned 32-bit). When the attacker sets `payload_size=3`
(any value < 13) in the MP4 file, the subtraction `payload_size - 13 = 3 - 13` underflows
to `0xFFFFFFF6` in unsigned 32-bit arithmetic. This is stored in `AP4_SubStream::m_Size`
(type `AP4_LargeSize` / `uint64_t`) as `0xFFFFFFF6`.

The inflated `m_Size` disables the DC substream's own bounds check
(`m_Position + bytes_to_read > m_Size`), allowing `CreateDescriptorFromStream(*substream)`
to seek to and read from offset `start+13 = 15` in the enclosing ES_Descriptor substream
– well outside the DC descriptor's claimed 3-byte payload.

## PoC Approach

`vuln_001_gen.py` crafts a minimal MP4 (`vuln_001.mp4`) where:

```
esds → ES_Descriptor (tag=0x03, payload=25 bytes):
  ES_ID=1, flags=0
  DecoderConfigDescriptor (tag=0x04, payload_size=3)  ← TRIGGER: 3-13 = 0xFFFFFFF6
    3-byte payload: [0x40 0x15 0x00]
  SLConfigDescriptor (tag=0x06, predefined=2)
  [7 padding bytes]    ← consumed by DC's 13-byte field reads (positions 2-14)
  DecoderSpecificInfo (tag=0x05, size=0)  ← at position 15: read by inflated DC substream
  [5 padding bytes]
```

ES substream has 22 bytes (positions 0-21). The DC substream starts at `start+13 = 15`,
which is within ES substream bounds (seek succeeds). `CreateDescriptorFromStream(*dc_substream)`
reads the fake `DecoderSpecificInfo` at position 15, creating an
`AP4_DecoderSpecificInfoDescriptor` with an empty (0-byte) payload and a null data pointer.

Later, `main()` calls `GetSampleDescription(0)` which invokes
`AP4_MpegAudioSampleEntry::ToSampleDescription()` → `AP4_MpegAudioSampleDescription()`
→ `AP4_DataBuffer::SetData(GetData(), GetDataSize())` where `GetData()` returns `nullptr`
(the empty DecoderSpecificInfo data buffer). UBSAN catches passing `nullptr` as a
`__nonnull` argument to `memcpy`.
