=== Analysis Notes ===
The vulnerability is in AP4_CencSampleInfoTable::AP4_CencSampleInfoTable():
  line 3007: m_IvData.SetDataSize(m_IvSize * sample_count)
With m_IvSize=16, sample_count=0x10000000:
  16 * 0x10000000 = 0x100000000 -> truncates to 0 (32-bit overflow)
  m_IvData.SetDataSize(0) -> m_IvData.m_Buffer stays NULL
  SetIv(0, data) -> memcpy(NULL, data, 16) -> OOB WRITE

Note: mp42aac uses AP4_SampleDecrypter::Create(pdesc,key,size) which returns NULL
for CENC scheme (only OMA/IAEC are handled). The crash requires the traf-aware
version: AP4_SampleDecrypter::Create(pdesc,traf,...) used by other Bento4 tools.
