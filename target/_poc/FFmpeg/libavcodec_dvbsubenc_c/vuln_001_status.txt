  - 14 DVB subtitle frames re-encoded via dvbsub encoder

No crash is observed because ffmpeg allocates a 1 MB output buffer
(subtitle_out_max_size=1024*1024); the 1-byte overflow writes into safe
slack space. The vulnerability is latent: any API caller passing a
minimum-sized buffer (buf_size=6 for w=2) would trigger a 1-byte
heap-buffer-overflow at dvbsubenc.c:267.

The buggy size check is at dvbsubenc.c:225:
